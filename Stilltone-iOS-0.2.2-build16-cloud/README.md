# Stilltone iOS 0.2.2 (16) · 修复候选源码

基于 Build 15，供桌面检查、macOS 构建和 iPhone 回归。**这是源码，不是签名安装包。**

## 使用这一份，不要混用历史目录

- **桌面预览：** 直接打开同目录的 `FL-Camera-Review.html` 与 `Stilltone-Album.html`。Xcode 会把这两份文件原样复制到应用。电脑浏览器没有 iPhone 的 PhotoKit/AVFoundation；可用格式、真实镜头、帧率和最终照片不能仅靠桌面确认。
- **Mac 真机：** 用 Xcode 16+ 打开 `FL-Camera.xcodeproj`，选择 FLCamera target 和连接的 iPhone（iOS 16+）。在 Signing & Capabilities 选择自己的 Team，必要时换成自己的唯一 Bundle Identifier，运行。需要相机权限；保存照片需要添加权限，浏览和基础编辑需要读写权限。系统模拟器不能替代物理镜头测试。
- **GitHub Actions：** 本包自带的工作流按**仓库根目录**查找工程。把解压后的目录内容（含 `.github/workflows/ipa.yml`、`Tests/` 和两个 HTML，不是 ZIP 文件本身）放在测试分支的仓库根目录。如果原仓库要保留按版本嵌套的目录，请调整相应工作流的工作目录与 `.github/workflows` 的位置，勿直接覆盖主分支。手动运行 **Build iPhone IPA** 后应看到 `Stilltone-0.2.2-build16-unsigned`。它产出未签名 IPA，不能当作可直接安装或上架的正式包。

## 优先在真机做的回归

| 操作 | 应看到什么 |
|---|---|
| 冷启动，等待后置主摄 1×；若格式面板列出 48 MP，选择它并再点 1× | 设备能力到齐后快门与格式可用。若硬件仍报告所选尺寸可用，设置不会被桌面演示的 12 MP 默认值覆盖。别把出现选项当作已验证成片。 |
| 在 1×、2× 间切换，再在 2× 退到后台并返回 | 倍率、格式徽标、分辨率列表一致。回前台按原有策略回到 1×，重新读取对应能力。在支持该模式的主摄上，变焦停止后可重新选择高分辨率。 |
| 打开滤镜条，边移动手机边来回拖动，再反复关、开 | 条中缩略图继续更新，退出后不再为隐藏的滤镜条做图；选中的主取景滤镜、快门和拍照保存仍工作。和 Build 15 在同光线、同温度下对比；如需帧率，用 Instruments 测，不以规格或上限作实测。 |
| 启用实况，再更改滤镜、曝光、比例、分辨率或切前摄 | 若新组合不能拍实况，图标和发送的拍照参数应同步退出实况。不支持的格式或尺寸不应凭空出现。实况的最终验收是在系统「照片」长按可播放。 |
| 用近、远两个物体，把近物放在 1:1 和 16:9 的取景边缘；竖屏、左右横屏和支持对焦的前后镜头分别点它 | 焦点对应点到的物体，而不是仅出现黄色方框。请同时试原图和滤镜预览。固定焦点镜头没有自动对焦动作。 |
| 用后置主摄拍 HEIF / RAW（仅试设备列出的选项） | 在系统「照片」详情或电脑上检查文件格式和实际像素。4:3、闪光/夜景/实况关闭时做基线；裁成正方形或 16:9 后像素会减少。RAW 是传感器数据，不烧录所选滤镜。 |

## 验证边界

无需第三方依赖，从解压后的根目录运行：

```
node Tests/camera-ui.test.cjs
node Tests/thumbnail-receiver.cjs
python Tests/verify_bundle.py
```

前两个命令也支持 Bun。第一组在模拟设备回报下运行真实的包内脚本，检查格式、倍率、Live、倒计时、滤镜手势与桌面回退。在这组针对性用例里，Build 15 是 6/25 通过，候选版是 25/25；这不是整机测试覆盖率。第二组对真实的缩略图接收函数模拟解码正常、关闭、失败和超时。滤镜条仍用每格 224 像素；现在等上一批显示完再取新帧，上限 12 批/秒，**不是主取景的帧率**。`verify_bundle.py` 检查版本、plist、工程引用、两份 HTML 和六份原生 LUT 的一致性；可追加源码 ZIP 路径逐个比较包内文件。

本机没有用 Xcode 编译或在 iPhone 实拍。构建、成片方向、实际像素、功耗和真机帧率请按上表验证。

此版仍以**照片**为主；视频／人像不是已实现的拍摄模式。原生手动夜景与桌面“自动”演示不是一回事。基础相册编辑通过 PhotoKit 写可还原的调整；高级网页修图导出 JPEG 副本，不是修改同一张系统原片。修复预览和交互不会补齐这些功能。
